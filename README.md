# Marco Ching portfolio

Static site served by GitHub Pages at https://kingmaching.github.io.

- `index.html` holds all the text. Search for `EDIT:` to find each section.
- `styles.css` holds colours (top of file, light and dark), fonts and layout.
- `script.js` runs the project tabs (deep-linkable as `#design`, `#research`, `#ai`) and the copy-email button.

To add a project image, put the file in the repo root and add a
`<figure class="figure">` block at the top of the project's `<article>`
(copy the one in the Robotic Crane project). Wide images around 5:1 or 16:9 work best.
